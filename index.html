    How this is computed

    Premium = (SKHY price × 10) / SKHYNIX price − 1. Each SK hynix ADR (Nasdaq: SKHY) represents one-tenth of a KRX common share (000660), so ten ADRs are compared with one share. The xyz:SKHX oracle is the won price of one common share converted to USD at the prevailing USD/KRW rate; the xyz:SKHY oracle tracks the ADR in USD.

    Mark premium uses Hyperliquid mark prices (tradeable 24/7). Oracle premium uses the deployer oracle prices, which only move while the underlying venue trades, so outside KRX or Nasdaq hours one leg is a stale reference. Executable premium uses the top of each order book (sell premium = SKHY bid × 10 / SKHYNIX ask; buy premium = SKHY ask × 10 / SKHYNIX bid). Carry for long SKHYNIX / short SKHY = SKHY funding − SKHYNIX funding, per hour, annualised (× 24 × 365). Charts use candle closes from Hyperliquid; the last point on the premium chart is the live mark premium.

    Sessions ignore exchange holidays. Data: Hyperliquid public API (api.hyperliquid.xyz), WebSocket with REST fallback. Nothing here is investment advice.
